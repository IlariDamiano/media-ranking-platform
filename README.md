# Media Ranking Platform

A full-stack web application for discovering, tracking,
rating, and organizing movies, TV shows, and manga.

## Planned Features

- Private user accounts
- Personal watchlists and reading lists
- Media ratings from 1 to 10
- Custom lists and rankings
- Media progress tracking
- English and Italian localization
- Responsive user interface
- External media catalog integration

## Technology Stack

### Backend
- Java 25
- Spring Boot
- Spring Security
- Spring Data JPA

### Frontend
- TypeScript
- React (planned)

### Database
- PostgreSQL

### Infrastructure
- Docker
- Docker Compose

## Project Structure

- `backend/` - Java Spring Boot application
- `frontend/` - Web application
- `infrastructure/` - Docker configuration
- `docs/` - Documentation

## Status

Early development — environment setup.

A personal learning project and professional portfolio
demonstrating Java backend and full-stack development.
